# LIT Proof of Work — Assignment Prototype

## Deploy on Vercel
1. Extract `lit-vercel-submission.zip`.
2. Open https://vercel.com/drop and sign in.
3. Drag the extracted folder (or ZIP) into Vercel Drop.
4. Name the project `lit-proof-of-work` and deploy.
5. Open the generated `vercel.app` URL in an incognito window and test the key flows.

This is a static HTML prototype. It does not require a build command or output directory.
For ongoing updates, connect the project to a Git repository and deploy from there.

## Included
- `index.html` — interactive responsive prototype
- `design-rationale.pdf` — product/design rationale for the assignment
- `design-rationale.md` — editable rationale source

## Prototype limitations to disclose
The prototype uses mock data and browser-local persistence. It is not connected to LIT OS and does not implement production authentication, server-side data persistence, secure file uploads, or a live recruiter messaging service. Any sample outcomes or recommendations should be treated as illustrative unless explicitly verified.
